# forme-hair
Hair tools website
Forme Hair - Web Engineering Assignment 1

This is a responsive multi-page website created using **HTML and CSS only** for a hair styling tools brand.

 Website Architecture

1. Page Details (9 Pages Total)
The website is composed of 9 HTML pages:
1. `index.html` - Home Page / Landing Page
2. `about.html` - About Us & Brand Story
3. `contact.html` - Contact Form & Location Details
4. `curlers.html` - Hair Curlers Catalog
5. `straighteners.html` - Hair Straighteners Catalog
6. `hairstyles.html` - Styling Inspiration & Lookbook
7. `faq.html` - Frequently Asked Questions
8. `tips.html` - Hair Care Advice & Articles
9. `stylers.html` - Multipurpose Styling Tools Showcase

2. Navigation Mechanism
- Navigation is handled using standard HTML anchor tags (`<a>`) enclosed within a top navigation bar (`<nav>`) present across all pages.
- Relative URL paths connect pages seamlessly without relying on JavaScript.
- Clear hover effects on navigation items provide visual feedback to users.

3. CSS Usage & Styling Technique
- External Stylesheet: All styling rules are centralized in a single external CSS file (`style.css`) linked across every HTML page via the `<link>` tag.
- **Layout Structure:** CSS Flexbox and CSS Grid are used for structural alignment, product card grids, and responsive containers.
- **Color Scheme & Typography:** Custom visual design with clean typography and consistent visual hierarchy.
- **Responsive Design:** Integrated `@media` queries ensure the layout adapts cleanly across mobile, tablet, and desktop screens.
